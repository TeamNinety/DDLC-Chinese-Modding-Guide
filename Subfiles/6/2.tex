\section{打包模组}
现在，打开Ren'Py Launcher，点击您的项目，在右边您应该可以找到一个选项名为“构建发行版”。点击后，Ren'Py 会自动扫描一遍您的项目。

扫描完成后，您会见到一个有许多选项的界面。首先，确保“选项”中的“向call语句添加from从句，执行一次”勾选了。
\begin{Warning}
    call语句在没有 from 从句的情况下，会有存档损坏的风险。
\end{Warning}
然后，取消“构建分发包”中的“PC：Windows and Linux”与“Macintosh”，勾选“Ren'Py 7 DDLC Compliant Mod”，点击“构建”按钮。稍等片刻，您的模组就会被Ren'Py编译打包成压缩包了。
\begin{Warning}
    请注意，在扫描项目与编译打包过程中，Ren'Py可能会“假死”。假死的时间取决于您电脑的配置与您模组的大小。在假死期间，不要强制关闭Ren'Py，您只需要静待其编译完成后自动恢复。若Ren'Py被强制关闭，其生成的模组很有可能是损坏的，需要重新生成。
\end{Warning}

打包完成后，Ren'Py会自动打开生成的模组的位置。打开压缩包，确保在其game/文件夹下没有audio.rpa、fonts.rpa与images.rpa后，您便可以上传您的模组共其他玩家游玩了。

2026年4月29日，Team Salvato更新了IP Guidelines。
根据现行IP Guidelines，您应该注意以下几件事：
\begin{enumerate}
    \item 关于模组：
    \begin{enumerate}
        \item 不得（CANNOT）在模组中直接包含DDLC及DDLC Plus原版内容；
        \item 模组中可以使用DDLC Plus与DDLC的素材，但必须（MUST）来自于玩家的本地安装；
        \begin{Comment}
            这里的“本地安装”是指玩家在电脑上安装了 DDLC 或 DDLC Plus。
            
            对于DDLC素材，模组可以直接从玩家的DDLC安装目录中读取素材，但不能直接在游戏内包含DDLC素材；

            对于DDLC Plus素材，除上述要求外还必须告知玩家拥有DDLC Plus才能游玩模组。（除了本身就可以直接使用的3张BG）
        \end{Comment}
        \item 模组不能（DO NOT）设计在DDLC之前游玩；
        \item 模组必须（MUST）是免费的，游戏内不能（MAY NOT）包含任何付款或捐赠链接，不得鼓励玩家在游戏中捐赠、购买商品或捐款；
        \item 应清晰标注您的模组并非Team Salvato的官方作品，不应（DO NOT）让玩家混淆您的模组与DDLC官方作品。
    \end{enumerate}
    \item 关于分发：
    \begin{enumerate}
        \item 可以（MAY）将您的模组上传到任何一个\textbf{仅PC}的集中式平台（如Steam、itch.io等）；
        \item 发布模组时，必须（MUST）在模组名里加上“[DDLC Fangame]”的字样；
        \item 模组的Logo必须（MUST）完全原创，不得是对原版DDLC标识的修改或衍生；
        \item 模组名不得（MUST NOT）包含“Doki Doki”字样；
        \item 除了截图部分，模组的宣传材料不得（MUST NOT）包含DDLC原版内容。
    \end{enumerate}
    \item 关于移植：
    \begin{enumerate}
        \item 必须（MUST）在下载页明确标明该游戏为移植版本；
        \item 不得（MAY NOT）将移植后的版本上传到任何平台。
    \end{enumerate}
    \item 关于AI的使用：
    \begin{enumerate}
        \item 不得（DO NOT）使用AI生成DDLC相关的内容（如文本、图像、音乐等）；
        \item 不得（DO NOT）将AI生成的DDLC内容作为商业用途；
        \item 不得（NEVER）将Team Salvato官方作品上传任何AI平台。
    \end{enumerate}
\end{enumerate}

4月版本的IP Guidelines较之前版本有了很大的调整。一方面是放宽了对于DDLC Plus素材的使用限制同时允许移植模组存在，另一方面对于模组的分发与AI使用有了更为严格的限制。总的来说，IP Guidelines的调整是为了更好地保护Team Salvato的知识产权，同时也为模组开发者提供了更多的创作空间。

您不应也不可以制作所谓的“解压即玩”、“傻瓜包”版（即包含原版DDLC内容）。请记住：保护知识产权不仅是保护作者的权利，更是在促进DDLC社区的良好发展。
